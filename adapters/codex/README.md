# Codex 适配器

## 两种用法

### 用法一：单独使用 Agent Prompt（推荐）

将需要的 agent prompt 替换占位符后，配置到 Codex 的 instructions / 自定义指令中。

**替换占位符**（在 prompt 文件中搜索替换）：

| 占位符 | 替换为 | 示例 |
|--------|--------|------|
| `{项目名称}` | 你的项目名 | `MyBlog` |
| `{代号}` | 简短英文代号 | `blog` |
| `{源代码目录}` | 源码目录 | `src/` |
| `{构建命令}` | 构建命令 | `npm run build` |
| `{依赖安装命令}` | 安装命令 | `npm install` |

替换后，在对话中直接说"按开发模式工作流程执行"或"测试任务 N"，AI 会按照 prompt 中定义的角色和规范工作。

### 用法二：自动编排（暂不支持）

自动编排（开发 → 测试 → 修正循环全自动）依赖 Claude Code 的 `Agent()` 调度能力，Codex 暂不支持。
